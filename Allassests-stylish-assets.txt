📊 A useful way to classify the whole 1,000-item list

Lifestyle	Typical physical assets

Very basic / low-income	Mat, simple bedding, basic utensils, clothes, basic phone, bicycle, basic tools
Lower-middle class	Cot, fan, TV, refrigerator, washing machine, smartphone, two-wheeler, basic furniture
Middle class	Full bedroom, kitchen appliances, computer/laptop, scooter/motorcycle, car, tools, appliances
Upper-middle class	Multiple electronics, car + two-wheeler, AC, better furniture, home office, larger appliances
Affluent	Large house, multiple vehicles, premium appliances, home theatre, gym, extensive workshop
Luxury	Smart home, premium vehicles, designer furniture, pool, home theatre, gym, large garden, extensive security
Very wealthy	Multiple properties, multiple vehicles, private facilities, large workshops, extensive automation and specialized equipment


This gives you a 1,000-item master physical-asset inventory, rather than only a list of things a man personally carries. Some items are personal assets, while others are shared household/property assets.
